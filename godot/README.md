# BeamNG.Earth на Godot 4.7 + C++

Новая версия игры (ветка `earthsim-godot`). Рендер Godot 4.7 (Forward+: GI, SSR, SSAO, тени, туман). Всё тяжёлое написано на C++ (расширение `earthcore`):
* генерация мира;
* стриминг карты;
* физика мягкого тела.

На GDScript только сцена, камера и интерфейс.

## Как получить exe
Вкладка **Actions** → **build-godot-windows** → последний запуск → **Artifacts → earthsim-godot-windows**. Распакуйте архив и запустите `earthsim.exe`. Рядом с exe должен лежать `libearthcore.dll`.

## Запуск
* `earthsim.exe` — Минск, данные качаются из интернета:
  * Overture Maps (дороги, здания, вода, парки, леса);
  * OSM через Overpass (этажность, подъезды, полосы);
  * рельеф AWS Terrain Tiles.

  Кэш хранится в `%APPDATA%\Godot\app_userdata\BeamNG.Earth (earthsim)\cache`.
* Свои координаты: `earthsim.exe -- --lat=48.8584 --lon=2.2945`.
* Другие параметры:
  * `--detail=700` — радиус детальной зоны, м;
  * `--far=2400` — радиус рельефа, м;
  * `--offline` — без сети, только кэш;
  * `--nogi` — выключить GI на слабых видеокартах;
  * `--time=19` — время суток.

## Управление
* W/S или стрелки — газ, тормоз и задний ход.
* A/D — руль.
* Space — ручник.
* R — поставить машину на дорогу (ремонт).
* C — камера: сзади, из салона или свободная.
* В свободной камере: I/J/K/L — полёт, Shift — быстрее, правая кнопка мыши — обзор.
* V — следующая машина BeamNG (встроенная → машины из папки `mods` рядом с exe → машины установленного BeamNG.drive).
* T — время суток.
* G — GI вкл/выкл.
* F1 — подсказка.
* Геймпад или руль: левый стик (руль), правый курок (газ), левый курок (тормоз), A (ручник).

## Машины BeamNG
Положите zip машины (мод BeamNG) в папку `mods` рядом с `earthsim.exe` — она загрузится сразу при старте. Если установлен BeamNG.drive (Steam), его машины доступны по клавише V, а недостающие детали модов берутся из его `common.zip`. Из BeamNG в игру ничего не входит: читаются только ваши файлы. Свой путь к BeamNG: переменная окружения `EARTHSIM_BEAMNG`.

## Что внутри
* **Мир собирается кусками 256×256 м** в фоновых потоках, ближние куски первыми.
* **Рельеф с шагом 1 м.**
  * Под дорогами рельеф выравнивается, под водой прокапывается.
  * Покрытие задаётся картой из 8 материалов.
* **Дороги:**
  * перекрёстки со скруглёнными бордюрами;
  * тротуары с бордюрным камнем;
  * разметка и зебры;
  * мосты с опорами;
  * фонари.
* **Здания.** Класс и стиль определяются по тегам Overture и OSM: серии панельных домов, храмы, школы, офисы. Сюда входят окна, балконы, подъезды, витрины и крыши.
* **Машина** — мягкое тело из узлов и балок, как в BeamNG:
  * сминается при ударах;
  * шины с комбинированным скольжением;
  * двигатель, сцепление и автомат;
  * ABS и антибуксовка.
* **Столкновения** машина считает с тем, что видно: дорогой, бордюрами, домами, фонарями, деревьями, машинами.
* **Трафик** ездит по дорогам с учётом полос и уклонов.
