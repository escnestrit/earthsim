# BeamNG.Earth v2 — вождение по реальной Земле

Игра для Windows: любая точка планеты по открытым данным (Overture Maps / OpenStreetMap + рельеф), физика
машины, стриминг мира вокруг. Минск и Брест лежат рядом с exe и работают без интернета; всё остальное игра
скачивает сама при выборе точки на карте мира и при подъезде к краю загруженного района (кеш на диске).
Ставить ничего не нужно: exe собирает GitHub Actions.

## Как получить exe
Вкладка **Actions** → workflow **build** → последний зелёный запуск → **Artifacts → earthsim-windows**.
Распакуйте архив и запустите `earthsim.exe`. Рядом должны лежать `libearthsim.dll` и папка `data`.

## Управление
| Клавиша | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз; удерживать на месте — включить заднюю, тогда S — газ назад |
| A / D | руль |
| Пробел | ручник |
| R | поставить машину на ближайшую дорогу |
| C | камера: сзади / с капота / облёт (правая кнопка мыши, колесо — дистанция) |
| Q / E | передача вниз / вверх (переключает на ручную КПП) |
| G | автомат / ручная |
| M | карта мира: клик — выбрать точку, «Поехать сюда» — перенестись (поиск по городам и координатам) |
| T / B | трекшн-контроль / ABS |
| N | +1 час (день/ночь) |
| F2 | дождь (мокрый асфальт, меньше сцепление) |
| F12 | скриншот (рядом с exe) |
| Esc | меню: карта, время и погода, настройки, управление |
| F4 | оси и кнопки руля/геймпада (для настройки `controls.cfg`) |
| F1 | список клавиш |
| F3 | FPS |

Геймпад / руль: оси задаются в `controls.cfg` рядом с exe (создаётся при первом запуске; по умолчанию
левый стик — руль, правый курок — газ, левый — тормоз, A — ручник). Нажмите F4, покрутите руль и нажмите
педали — увидите номера осей. Обратная связь руля (force feedback) пока не поддерживается.

## Параметры запуска
`earthsim.exe -- --lat=53.9023 --lon=27.5619 --time=21 --rain --radius=1200 --traffic=40`
(`--notraffic` — без машин).

## Весь мир
* **Карта мира (M)** — рельеф всей планеты, дороги при приближении, поиск по ~100 городам или по координатам
  («48.8584, 2.2945»). Выбранный район (≈3,6×3,6 км) скачивается за 10–60 с и кешируется в
  `%APPDATA%/Godot/app_userdata/BeamNG.Earth/cache`.
* **Бесконечная езда** — у края района игра в фоне подгружает следующий и переключается без остановки.
* **Местные особенности** по координатам: архитектура (постсоветская, Восточная/Западная Европа, Северная
  Америка, Латинская Америка, жаркий пояс, тропики, Восточная Азия, Австралия), правостороннее или
  левостороннее движение, климат (умеренный, тайга, средиземноморье, пустыня, тропики, тундра — цвет земли,
  пальмы/хвойные). Центр города определяется по плотности застройки, а не по точке старта.

## Что внутри
* **Ядро мира (C++, `core/`)** — единая модель: граф дорог Overture (узлы из коннекторов, мосты/туннели/уровни
  по участкам), высоты дорог с пандусами к мостам и туннелям, перекрёстки с закруглёнными бордюрами, тротуары
  (кроме разделительных полос), рельеф, подогнанный под дороги (насыпи и выемки), здания на итоговой поверхности,
  вода, тропинки, рельсы, деревья, фонари, светофоры по картографическим данным.
* **Коллизия = те же треугольники, что и картинка**, поэтому колёса не «плывут» и не «жуют» бордюры.
* **Игра (Godot 4.7, `game/`)** — рендер, стриминг чанков 256×256 м в фоновых потоках плюс дальний план всего
  региона, машина: подвеска на лучах, модель шин Pacejka с эллипсом трения, вращение колёс с подшагами,
  двигатель с кривой момента, сцепление, автомат/ручная КПП, ABS, трекшн, аэродинамика, деформация кузова
  при ударах (R — ремонт), процедурный звук двигателя/шин/ветра, день и ночь, дождь, трафик (держит полосу
  и дистанцию, стоит на красный — фазы те же, что у видимых светофоров).
* **Автотесты** в CI: проверки качества модели мира на реальных данных (рельеф не протыкает дороги и тротуары,
  здания не ниже тротуара и без щелей, бордюр 15 см, время сборки чанка) и тест физики машины.

## Офлайн-регионы
Чтобы район работал без интернета, его можно вшить в сборку: откройте на GitHub файл `regions.txt` (ветка `v2`), нажмите ✏️ и добавьте строку, например:
```
paris 48.8566 2.3522 2500
```
После сохранения CI сам скачает открытые данные (Overture Maps + рельеф) в ветку `data-paris` и пересоберёт
игру. Радиус 2500 м ≈ 7×6 км; больше — дольше загрузка.

## Данные
См. `ATTRIBUTION.md`. Данные каждого региона лежат в ветке `data-<название>` и попадают в сборку автоматически.
