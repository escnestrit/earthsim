# True Torque

Мультиплеерная автомобильная песочница на Unreal Engine 5.5 (Lumen, Virtual Shadow Maps, атмосфера, облака).
Без HUD, ремонт гайка за гайкой, визуальные повреждения кузова в духе Matrix Awakens.

## Как устроено
* **Физика машины** — одно твёрдое тело Chaos (стабильные столкновения со стенами и другими машинами), лучевая
  подвеска с пружинами, амортизаторами и стабилизаторами, шины со скольжением и эллипсом трения, двигатель с
  кривой момента, сцепление, 6 передач (автомат/ручная), самоблок, тормоза с ABS, ручник. Сцепление зависит
  от покрытия (асфальт/трава).
* **Повреждения** — визуальные: панели мнутся по месту удара (глубина и радиус зависят от скорости удара),
  складки, слезает краска до металла, трескаются стёкла. Бамперы, капот и крышка багажника отлетают и
  катаются как отдельные предметы. Удар колесом гнёт подвеску (машину тянет, колесо косит), сильный — колесо
  отрывается. Лобовые удары бьют по двигателю (меньше мощности, стук, может заглохнуть).
* **Модели** — пока процедурный седан (`Source/TrueTorque/Geom`). Повреждения работают с любой сеткой,
  позже подключаются свои модели.
* **Сеть** — сервер считает физику и повреждения, клиенты получают движение, управление и каждую вмятину.

## Порядок запуска (один раз)
1. Закрыть редактор. `compile.bat` → в `compile.log` должно быть `COMPILE OK`.
2. `make_assets.bat` → создаёт материалы в `/Game/TT/Materials` (краска с лаком и повреждениями, стекло,
   асфальт, трава, бетон…). Без них игра тоже идёт, но всё серое.
3. Открыть `TrueTorque.uproject`, Play. Или `build.bat` → готовая игра в `Build\Windows`.

## Управление
* W/S — газ/тормоз (на автомате: держать S на месте — задний ход), A/D — руль, Пробел — ручник,
  Q/E — передачи (включают ручную), M — автомат/ручная, L — фары, C — камера (сзади / из салона),
  мышь — обзор, R — поставить на колёса.
* Tab (стоя на месте) — режим механика, смотришь на деталь мышью:
  ЛКМ по колесу — затягивать гайки ключом (120 Н·м; перетянешь — сорвёшь резьбу), ПКМ — открутить,
  F — выправить кузов / поставить отлетевшую деталь / поставить колесо (потом затянуть гайки!),
  G — отремонтировать двигатель. Недотянутые гайки откручиваются на ходу — колесо уедет.
* `play_host.bat` — свой сервер, `play_join.bat IP` — подключиться (порт 7777 UDP).

## Проверки без движка
`cmake -S . -B build && cmake --build build && ./build/geom_tests` — геометрия машины (ориентация граней,
размеры), вмятины (ограничены, локальны, внутрь), царапины, ремонт. `geom_preview` пишет OBJ до/после удара.
Старый прототип мягкого кузова лежит в `legacy_softbody` (в игре не используется).
